# 製品コンセプト v0.1

## 目的
このアプリは簿記2級工業簿記の「問題集」ではない。
工場の中で原価がどう生まれ、移動し、在庫となり、費用となり、利益につながるかを視覚的・操作的に理解させる。
理解した内容を「問題文を見た瞬間の初動」「解く順番」「仕訳・計算の反射」に変換し、最終的にCBT本番を補助なしで解ける状態まで持っていく。

## 5原則
1. ユーザーを現在地で迷子にさせない。
2. 用語より現象を先に理解させる。
3. 同じ数字を工場・仕訳・T勘定・B/S・P/Lでつなげる。
4. 正誤ではなく誤概念まで記録する。
5. 理解 → 手順 → 反射 → CBTへ、補助を徐々に消す。

## UI共通ルール
各学習画面には可能な限り次の3点を表示する。
- どこ？：工業簿記全体の現在地
- 何を？：現在処理している対象
- なぜ？：その計算・仕訳をする目的

## オリジナリティ方針
- 特定教材の文章・図・配色・問題・画面構成をコピーしない。
- 日商簿記の出題範囲・一般的な会計理論を基礎に、複数資料で事実確認する。
- 独自の視覚言語として「原価の居場所」「原価の旅」「現在地」「初動反射」「誤概念診断」を中心に設計する。
