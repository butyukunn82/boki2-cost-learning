# boki2-cost-learning

簿記2級の工業簿記・原価計算を「現在地・つながり・可視化・初動反射・誤概念診断・CBT」で学ぶWebアプリ。

## 画面構成

アプリは4モードで整理する。

- **学ぶ**：全体地図 / 原価の旅 / 製造原価報告書 / 個別原価計算 / 総合原価計算 / 平均法 vs FIFO / 追加材料 / 正常仕損・工程別 / 組別・等級別 / 部門別計算
- **動かす**：材料費差異 / 労務費差異 / シュラッター図 / 全部原価 vs 直接原価 / CVP
- **鍛える**：学習ダッシュボード / 弱点復習 / 初動反射 / 工業簿記30型
- **本番**：CBT Practice

最後に開いていたモードと論点はlocalStorageに保存し、次回も同じ場所から再開する。

## 現在の実装

### 全体地図・原価の流れ
- **全体地図**：工業簿記の論点を「原価の旅 / 原価を測る・分ける / 標準と実際を比べる / 利益につなげる」の4群に配置
- **原価の旅**：材料 → 仕掛品 → 製品 → 売上原価を、工場 / 仕訳 / T勘定 / B/S・P/Lで同期表示
- 迷ったときは「いま原価はどこ？ / 何を分ける？ / 結果は次にどこへ行く？」へ戻る設計

### 原価計算
- **製造原価報告書**：直接材料費・直接労務費・製造間接費 → 当期総製造費用 → 月初仕掛品を加算 → 月末仕掛品を控除 → 当期製品製造原価、という流れを仕掛品T勘定と同時表示
- **個別原価計算**：製造指図書No.ごとに直接材料費・直接労務費・予定配賦製造間接費を集計。未完成は仕掛品、完成すると製品へ移動
- **総合原価計算**：数量と完成品換算量を分離。工程始点投入材料と加工費の進捗度を区別
- **平均法 vs FIFO**：月初仕掛品を「混ぜる / 分ける」の違いを換算量・単価・原価配分で比較
- **追加材料**：始点投入・途中一括投入・平均投入を切替。投入点と月末仕掛品進捗度から追加材料の完成品換算量を判定
- **正常仕損**：仕損発生点と月末仕掛品進捗度から完成品のみ負担 / 両者負担を可視化。材料換算量と加工換算量も分離
- **工程別原価計算**：前工程費を次工程へ100%引き継ぎ、当工程加工費だけ進捗度を反映
- **組別原価計算**：種類ごとの固有原価と共通原価の配分を可視化
- **等級別原価計算**：数量×等価係数で積数へ直し、完成品総合原価を等級別に配分
- **部門別計算**：簡便法の相互配賦を第1次・第2次の2段階で可視化

### Visual Lab
- **直接材料費差異**：SP / AP / SQ / AQ、価格差異・数量差異、混合部分を段階表示
- **直接労務費差異**：SR / AR / SH / AH、賃率差異・作業時間差異を「標準 → SR×AH → 実際」の長方形で表示
- **製造間接費差異**：シュラッター図、基準・実際・標準操業度、予算・能率・操業度差異
- **全部原価 vs 直接原価**：固定製造間接費がB/S在庫に残るかP/Lへ落ちるかを追跡
- **CVP**：販売単価・変動費・固定費を動かし、損益分岐点・貢献利益率・目標利益を連動表示

### 鍛える
- **学習ダッシュボード**：初動速度・30型・CBT履歴を横断表示し、弱点ランキングと次の学習候補を提示
- **弱点復習**：遅答・誤答・CBT誤答を「誤概念」へまとめ、15秒の矯正問題を自動キュー化
- 弱点復習は、完成品換算量 / 製造原価報告書 / 個別原価 / 追加材料 / 正常仕損 / 工程別 / 等級別 / 部門別 / 材料差異 / 労務費差異 / 製造間接費差異 / CVP / 全部・直接原価などへ対応
- **初動反射**：問題文を見て「最初に何をするか」を3〜5秒で回答。正解でも遅ければ復習対象
- **工業簿記30型**：仕訳・勘定移動12型＋解き順18型を「合図 → 初動 → 手順 → ひっかけ」で反射化

### CBT Practice
- 90分タイマー、問題切替、選択式・数値入力式、見直し、未回答表示
- 終了まで正誤を表示しない
- 得点・所要時間・誤答論点をlocalStorageへ保存
- 基礎10テンプレート＋追加テンプレートから候補を生成し、毎回5題を抽出
- 対応論点：勘定連絡 / 製造原価報告書 / 個別原価 / 完成品換算量 / 追加材料 / 正常仕損 / 等級別 / 材料費差異 / 労務費差異 / 工程別 / 部門別 / CVP / 全部原価と直接原価
- 問題文・正解・診断を同じパラメータから生成して数値ズレを防止
- CBTで落とした論点は弱点履歴へ入り、15秒復習へ戻せる

### PWA / スマホ基盤
- Web App Manifest / Service Workerを追加
- インストール可能な環境では「ホーム画面に追加」の案内を表示
- ホーム画面からスタンドアロン起動できる構成
- 同一オリジンの読み込み済み資産をキャッシュし、オフライン時も開きやすくする
- モード・論点・学習履歴は端末内に保持
- スマホでは4モードナビと論点ナビを上部に固定し、論点を横スワイプで切替
- タップ領域を広げ、長いLabの途中からでも移動しやすく調整

## 2026年度の試験範囲

2026年度は2022年度適用の出題区分表を基準に実装する。2027年度も工業簿記・原価計算部分は変更なしと日本商工会議所が公表しているため、継続して範囲監査を行う。

## 学習設計の核

1. ユーザーを現在地で迷子にさせない
2. 用語より先に現象を理解させる
3. 同じ数字を工場・仕訳・T勘定・B/S・P/Lでつなげる
4. 正誤ではなく「誤り方」を記録する
5. 正解しても遅ければ復習対象にする
6. 理解 → 操作 → 手順 → 反射 → CBT の順で補助を徐々に消す
7. 問題データは「パラメータ → 正解 → 解説」を一元生成する
8. CBT誤答 → 誤概念 → 短い矯正 → 再挑戦、の循環を作る
