# boki2-cost-learning

簿記2級の工業簿記・原価計算を「現在地・つながり・可視化・初動反射・誤概念診断・CBT」で学ぶWebアプリ。

## v0.2
最初の縦切り「原価の旅」を、直接費・間接費まで含む動的UIへ拡張。

- 材料 → 仕掛品 → 製品 → 売上原価
- 直接材料費・直接労務費は仕掛品へ直行
- 間接材料費・間接労務費・間接経費はいったん製造間接費へ集めてから仕掛品へ配賦
- 工場 / 仕訳 / T勘定 / B/S・P/L を同じデータで同期
- B/SとP/Lの境界を可視化
- 「どこ？・何を？・なぜ？」に加え「問題を見たらまず何を見る？」を表示
- 流れを1ステップずつ送って、現在の原価移動をアニメーション表示
- 数値スライダーで状態変化を確認

## 学習設計の核

1. 原価は消えずに「居場所」が変わる
2. 直接費と間接費では、仕掛品へ入るまでのルートが違う
3. 売れるまではB/S、売れた瞬間にP/Lへ移る
4. 用語より先に現象を理解し、その後で名称を付ける
5. 最終的には図やヒントを消し、CBT本番で自力再現できる状態へ移行する
