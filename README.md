# boki2-cost-learning

簿記2級の工業簿記・原価計算を「現在地・つながり・可視化・初動反射・誤概念診断・CBT」で学ぶWebアプリ。

## v0.1
最初の縦切りは「原価の旅」。

- 材料 → 仕掛品 → 製品 → 売上原価
- 工場 / 仕訳 / T勘定 / B/S・P/L を同じデータで同期
- 「どこ？・何を？・なぜ？」を常時表示
- 数値スライダーで状態変化を確認

## 起動
```bash
npm install
npm run dev
```
