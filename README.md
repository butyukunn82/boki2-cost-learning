# boki2-cost-learning

簿記2級の工業簿記・原価計算を「現在地・つながり・可視化・初動反射・誤概念診断・CBT」で学ぶWebアプリ。

## 画面構成

アプリは4モードで整理する。

- **学ぶ**：原価の旅 / 総合原価計算 / 平均法 vs FIFO / 部門別計算
- **動かす**：材料費差異 / シュラッター図 / 全部原価 vs 直接原価 / CVP
- **鍛える**：初動反射 / 工業簿記30型
- **本番**：CBT Practice

最後に開いていたモードと論点はlocalStorageに保存し、次回も同じ場所から再開する。

## 現在の実装

### 1. 原価の旅
- 材料 → 仕掛品 → 製品 → 売上原価
- 直接材料費・直接労務費は仕掛品へ直行
- 間接材料費・間接労務費・間接経費はいったん製造間接費へ集めてから仕掛品へ配賦
- 工場 / 仕訳 / T勘定 / B/S・P/L を同じデータで同期
- B/SとP/Lの境界を可視化
- 「どこ？・何を？・なぜ？」と「問題を見たらまず何を見る？」を常時表示

### 2. 総合原価計算
- 数量と完成品換算量を分離
- 材料は工程始点投入なら100%、加工費だけ進捗度を反映
- 月末仕掛品数量・進捗度を動かして違いを確認

### 3. 平均法 vs 先入先出法
- 平均法＝月初仕掛品原価＋当月原価を混ぜる
- FIFO＝月初仕掛品の残作業と当月着手分を分ける
- 材料・加工の完成品換算量、単価、完成品原価、月末仕掛品原価を同時表示
- 投入原価合計と配分後原価を検算

### 4. 部門別計算・簡便法の相互配賦法
- 第1次配賦＝他の補助部門も含めて配る
- 第2次配賦＝第1次で受け取った補助部門費を製造部門だけへ配る
- 動力部・修繕部から製造部門へ原価が移る流れを可視化
- 最終製造部門費と全部門費合計を検算

### 5. 直接材料費差異
- SP / AP / SQ / AQ を4つに分ける
- 標準 → 標準価格×実際数量 → 実際 の順で差異を分解
- 価格差異・数量差異を動く長方形で表示
- 混合部分が価格差異側に含まれる理由を段階表示

### 6. 製造間接費差異
- シュラッター図が「製造間接費だけの差異分析」であることを現在地表示
- 基準操業度・実際操業度・標準操業度を可視化
- 予算差異・能率差異・操業度差異を表示
- 能率差異を「変動費のみ」「変動費＋固定費」の2方式で切替
- 3差異の合計と総差異を検算

### 7. 全部原価計算 vs 直接原価計算
- 固定製造間接費の「居場所」を追跡
- 全部原価では未販売分が製品原価としてB/Sへ残る
- 直接原価では固定製造間接費を当期P/Lへ
- 利益差と期末在庫に残る固定製造間接費を連動表示
- Partial（部分）の意味を用語ではなく処理の違いから理解

### 8. CVP
- 販売単価・変動費・固定費をスライダー操作
- 売上線・総費用線・固定費線・損益分岐点をリアルタイム表示
- 貢献利益、貢献利益率、目標利益、安全余裕率まで連動

### 9. 初動反射トレーナー
- 最後まで計算せず「問題文を見たら最初に何をするか」だけを3〜5秒で回答
- 正解でも5秒を超えれば復習対象
- 誤答・回答速度・弱点タグをlocalStorageへ保存
- 弱点ランキングを自動集計

### 10. 工業簿記30型トレーナー
- 仕訳・勘定移動12型＋解き順18型
- 問題文の合図 → 最初の一手 → 仕訳/解き順 → ひっかけ警戒
- 5秒以内の正答を反射化として記録
- 型ごとの習熟履歴をlocalStorageへ保存

### 11. CBT Practice
- 90分タイマー
- 5題以内を想定した問題切替
- 選択式・数値入力式
- 見直しフラグ・未回答表示
- 終了まで正誤を表示しない
- 終了後に得点・論点別診断
- v1は工業簿記・原価計算のオリジナル5題

## 2026年度の試験範囲

2026年度は2022年度適用の出題区分表が引き続き適用される。2027年度も工業簿記・原価計算部分は変更なしと日本商工会議所が公表しているため、当アプリはこの範囲を基準に監査する。

## 学習設計の核

1. ユーザーを現在地で迷子にさせない
2. 用語より先に現象を理解させる
3. 同じ数字を工場・仕訳・T勘定・B/S・P/Lでつなげる
4. 正誤ではなく「誤り方」を記録する
5. 正解しても遅ければ復習対象にする
6. 理解 → 操作 → 手順 → 反射 → CBT の順で補助を徐々に消す
